# GoonOnTheGo

> **Citace o vzniku projektu:** Tento web vznikl za pomoci umělé inteligence, která pomohla s návrhem a vytvořením jeho struktury, vzhledu i funkcí. Výsledkem je jednoduchá stránka inspirovaná vyhledávačem Google, včetně vyhledávacího pole, tlačítek a navigace na další stránky. Vytvořený obsah a kód byly následně zkontrolovány a upraveny pro potřeby tohoto projektu. Umělá inteligence zde sloužila jako nástroj při tvorbě; konečnou podobu a použití projektu určuje jeho autor.

Podrobnosti o použití AI při tvorbě portfolia a začlenění tohoto projektu najdeš v [citaci AI](../../CITACE-AI.md).
